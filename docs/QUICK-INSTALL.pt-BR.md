# Instale o Drive Assist

[English](QUICK-INSTALL.md) · **Português (Brasil)**

A instalação mais simples usa um único arquivo e um pen drive. O carro já deve
estar preparado para instalar aplicativos de terceiros. Faça a instalação com o
carro estacionado.

> [!WARNING]
> Se você ativou o ADB root para preparar o carro, entenda [o poder desse acesso](ADB-ROOT-SAFETY.pt-BR.md).
> Desligue o ADB pela rede depois da instalação e só instale APKs de uma fonte confiável.

1. Baixe o arquivo `drive_assist_installer.apk` na página da versão do projeto.
2. Copie o arquivo para um pen drive formatado em FAT32.
3. Conecte o pen drive ao carro e abra o Gerenciador de Arquivos da central.
4. Toque no instalador e siga as instruções da tela.
5. Abra o Drive Assist quando a instalação terminar.

O instalador adiciona o Drive Assist e seu auxiliar ModeHelper. O ModeHelper
permite restaurar preferências e usar as funções compatíveis do veículo. Você não
precisa instalar os dois componentes separadamente. O instalador temporário remove
a si mesmo quando termina. Consulte o [inventário dos componentes instalados](ADB-ROOT-SAFETY.pt-BR.md#saiba-o-que-o-instalador-do-drive-assist-adiciona)
para ver os nomes dos pacotes e como verificá-los.

Se o arquivo não abrir, talvez a central ainda não esteja preparada para instalar
aplicativos de terceiros. O [guia técnico de instalação](INSTALL-GUIDE.md) explica
desbloqueio, ADB, instalação pelo computador, verificação e solução de problemas.
