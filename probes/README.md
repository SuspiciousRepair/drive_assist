# Probes

Small test apps and experiments for the head unit. They are not part of
Drive Assist and are not installed by it.

| Folder | What it is |
| --- | --- |
| `owwprobe/` | Wake-word test app (a Gradle module, `:owwprobe`). See its README. |
| `voiceprobe/` | Voice assistant phase 0 tests. See its README and `PHASE0-RESULTS.md`. |
| `sysprobe/` | SysProbe (`com.geely.sysprobe`), an optional engineering tool. See `docs/ADB-ROOT-SAFETY.md`. |

Other probe folders can exist here on a developer's machine without being
in git.
